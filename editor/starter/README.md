# Backtest starter

Evaluate forecasts in time order with a gap for delayed observations and disjoint test windows.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Backtest** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
4
25
30
5
```

The vendor directory contains the framework source for 0.1.1 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/backtest) · [View the release](https://github.com/Rahulchaube1/blyx-backtest/releases/tag/v0.1.1)
